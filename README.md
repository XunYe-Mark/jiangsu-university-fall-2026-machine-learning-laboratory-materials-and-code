## 运行方法

五个实验脚本已在 MATLAB R2025b 中分别运行验证。

1. 下载或克隆仓库，在 MATLAB 中进入要运行的子实验文件夹。实验一的工作目录是 `学生模型_Work`。
2. 打开表中的 `.m` 文件，点击 **运行** 或按 **F5**。
3. 实验一会打开决策树图，并在命令窗口显示两个样本的预测标签，均为「否」。其余实验会将结果保存在脚本所在的文件夹，再次运行时更新同名文件。

两个 SVM 子实验需要 **Statistics and Machine Learning Toolbox**。决策树仿真和 BP 神经网络逼近二次函数只需 MATLAB。BP 鸢尾花分类需要 **Statistics and Machine Learning Toolbox** 和 **Deep Learning Toolbox**。

## 实验说明

- 实验设置参考江苏大学《机器学习》课程讲义。
- 两个鸢尾花实验都用 MATLAB 示例数据 `fisheriris`。SVM 用 10 折交叉验证评估，BP 神经网络按类别划分训练集和测试集，各使用 75 个样本。
- BP 二次函数实验按讲义将样本的真实函数值作为第二个网络输入，用于观察训练过程中的逼近误差。
